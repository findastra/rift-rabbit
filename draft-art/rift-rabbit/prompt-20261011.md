# Rift Rabbit art draft

Original design for Astra, generated with the built-in imagegen tool by OpenAI Codex (GPT-6), 2026-10-11. No paid API or CLI was used. This is a draft awaiting owner review, and is not wired into the live app.

## Exact prompt

Create original Astra's pet app pixel-art sprite sheet for RIFT RABBIT, a cute plump white rabbit who prepares VR software. A three-by-three grid of the SAME character, identical centered body/pose/palette/scale in all nine cells. Ice-white round rabbit, long upright ears with electric-violet interiors, small cyan VR visor resting raised ON TOP OF ITS FOREHEAD so the two eyes remain fully visible, small violet collar and pale teal paws, soft round tiny tail. Distinctive but simple readable silhouette. Fine polished SNES pixel art roughly80 pixels tall per character; crisp flat hard pixel edges, solid one-pixel BLACK outline throughout, no antialiasing no gradients no3D. Small symmetric black dot eyes each with one white highlight, pink blush cheeks. Rowmajor expressions exactly: neutral open eyes, blink both eyes closed, happy smiling, curious via eyebrow and mouth ONLY with eyes symmetric same as idle, worried, sad, tired/unwell, shocked, sleeping. Do not change pose or body between moods; no punctuation letters symbols sweat tears bandages logos or text. No copying an existing mascot. Each whole character comfortably fits within equal square cells, evenly spaced3x3 with transparent gutters, no gridlines. Genuine transparent RGBA background. This is a new DRAFT pet design.

## Conversion

The transparent 3x3 sheet was sliced with the hub's scripts/build-desktop-art-20261011.mjs into nine 256px frames using a shared scale and original alpha. No mood stickers were generated. The neutral frame is the proposed app icon. Original source sheet is retained.
